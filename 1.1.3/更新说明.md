# 识字系统 更新说明

## v1.1.2（基于 v1.1.1，2026-07-29）

### 新增功能

**1. 账号注册与登录**
- 支持注册账号（用户名 2-20 字符，密码至少 6 位）
- 登录后导航栏显示用户名，可随时退出登录
- 密码使用 bcrypt 加密存储，登录返回 JWT Token（有效期 30 天）
- 登录状态保存在本地，刷新页面不丢失

**2. 多设备数据同步**
- 登录后可点击"☁️ 同步"按钮，将本地学习记录上传到云端
- 服务端自动合并本地与云端数据，无需手动处理冲突
- 合并策略：
  - 汉字记录：取各设备中最大的对/错/连续/最后测试值
  - 测试记录：按记录 ID 去重，保留所有唯一记录
  - 自定义汉字组：按组 ID 合并，较新的修改覆盖旧的
- 登录时自动同步一次（下载云端数据合并到本地）
- 统计页新增"☁️ 云端同步"按钮，方便快速同步

**3. 同步服务端**
- 新增 `server/` 目录，包含 Node.js 后端服务
- API 接口：注册、登录、上传同步、下载同步、健康检查
- 数据使用 JSON 文件存储（`database.json`），无需额外数据库

**4. 移动端适配增强**
- 锁定页面缩放：viewport 设置为 `width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`，手机端无法双指缩放或双击放大
- 禁止文字自动调整和双击缩放：body 添加 `-webkit-text-size-adjust: 100%` 和 `touch-action: manipulation`
- 新增 `@media (max-width: 768px)` 响应式样式，全面适配手机屏幕：
  - 导航栏自动换行、字号缩小、按钮紧凑排列
  - 弹窗宽度自适应（92% 宽度，适配各种手机屏宽）
  - 输入框和按钮增大触摸区域（padding 加大、字号 ≥16px 防 iOS 自动放大）
  - 统计卡片、筛选栏、测试记录卡片、汉字组卡片均针对窄屏优化
- 手机端访问 `http://电脑IP:3001` 时页面自动适配，无需手动缩放

### 使用方法

**1. 启动服务端**（在一台电脑上运行，作为同步中枢）

```
cd 1.1.2/server
npm install    # 首次安装依赖
npm start      # 启动服务，运行在 http://localhost:3001
```

服务端启动后，会同时提供 API 和前端页面。其他设备只需用浏览器访问即可，无需单独安装前端。

**2. 电脑上使用**：直接访问 `http://localhost:3001`

**3. 手机上使用**（需与电脑在同一局域网/WiFi）：
   - 电脑上查看局域网 IP（命令行执行 `ipconfig`，找 IPv4 地址，如 `192.168.1.2`）
   - 手机浏览器访问 `http://电脑IP:3001`（如 `http://192.168.1.2:3001`）
   - 前端会自动检测服务器地址，无需手动填写

**4. 注册与同步流程**：
   - 电脑上：访问页面 → 点"登录"→ 切换"注册"→ 创建账号 → 做测试 → 点"☁️ 同步"上传
   - 手机上：访问页面 → 登录同一账号 → 自动下载电脑上的记录 → 继续学习 → 点"☁️ 同步"上传
   - 任何时候在任一设备点"☁️ 同步"，都会将本地数据与云端合并

**5. 注意事项**：
   - 电脑上的服务端必须保持运行，手机才能连接
   - 手机和电脑需在同一局域网（或服务端有公网 IP/内网穿透）
   - 如需外网访问，可将服务端部署到云服务器，填写其公网地址

## v1.1.1（基于 v1.1.0，2026-07-28）

### 新增功能

**1. 测试 / 复习记录系统**
- 自动记录每一次测试和复习会话
- 每条记录包含：起始时间、结束时间、测试时长、测试汉字列表、测试类型（测试 / 复习）、答对数、答错数、正确率
- 自动持久化到 `localStorage.quizHistory`，最多保留最近 200 条

**2. 独立的"测试记录"页面**
- 统计与记录分离，新增第 5 个导航页"测试记录"
- 以卡片形式展示历次测试：可读时间、时长、汉字内容、正确率
- 提供一键清空所有记录

**3. 再测一次**
- 每条记录卡片提供"🔁 再测一次"按钮
- 一键载入该次测试的汉字到输入框并重新开始测试

**4. 统计页面排序**
- 统计页筛选栏新增排序下拉框，提供 4 种排列方式：
  - 时间倒序（默认）
  - 时间顺序
  - 错误频率倒序（错字最多的在前）
  - 错误频率顺序（错字最少的在前）
- 每个汉字记录新增 `lastTested` 字段，每次答题后更新，用于时间排序

### Bug 修复

- **修复时间戳格式导致答题无反应的问题**
  - 现象：直接点击右上角"测试"开始测试时，点击"认识 / 不认识"均没有任何反应
  - 原因：`startTime` / `endTime` 保存为时间戳格式（如 `1785195491397`），未转成可读日期
  - 修复：新增 `formatDateTime()` 将时间戳格式化为可读格式（如 `2026-07-28 07:41`），记录同时保存时间戳与可读字符串 `startTimeStr` / `endTimeStr`

### 数据兼容

- 导出数据（JSON）包含测试记录 `quizHistory`
- 导入时自动合并测试记录，按记录 id 去重，不覆盖已有记录
- 兼容旧版导出文件：自动补全 `lastTested`、`startTimeStr`、`endTimeStr` 字段

## v1.1.0（基于 v1.0.9，2026-07-28）

### 新增功能

**用户新建常用汉字组**
- 首页支持创建自定义汉字组，保存到 `localStorage.customGroups`
- 可为汉字组命名、添加汉字、随时编辑
- 一键载入汉字组开始测试，支持删除已有汉字组
