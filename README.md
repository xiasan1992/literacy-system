# 汉字识别学习系统 (Chinese Character Recognition System)

一个专门为儿童设计的电脑端汉字识别与测试系统。界面美观、互动性强，支持超大字号显示、自由汉字输入、预设词库（如《小羊上山》分级读物生字库）、自动错题记录与专项复习，以及永久数据持久化存储。

---

## 🌟 系统核心功能与特点

1. **80% 屏幕占比大字显示**
   - 适配电脑大屏，采用超大字号和护眼田字格背景，极度适合儿童认字与朗读。
   - 搭配流畅的切字动画与反馈声效/视觉反馈。

2. **丰富且精准的预设字库（内置《小羊上山》全套）**
   - **《小羊上山》第 1 ~ 6 级完整生字库**，一键选择加载。
   - 基础汉字、自然万物、身体部位、家庭成员、动物世界、颜色大小等丰富主题预设。
   - 点击预设自动覆盖输入框，确保测试汉字干净精确。

3. **科学的“已掌握”判定与“连胜”机制**
   - **从未错过的字**：答对 1 次即标记为掌握。
   - **曾经答错的字**：必须**连续答对 3 次**（`streak = 3`）才会被判定为真正掌握，帮助巩固薄弱项。

4. **预设卡片动态掌握率分析**
   - 常用汉字组卡片实时展示**掌握率百分比**与**已掌握/总字数**。
   - 醒目列出**当前尚未掌握的汉字列表**，学习进度一目了然。

5. **错题集与专项复习**
   - **全局错题复习**：从历史答题记录中筛选未掌握的字进行强化训练。
   - **组内错题复习（复习其中错字）**：支持针对当前选中的特定汉字组进行精准错题复习。

6. **数据自动持久化**
   - 基于浏览器 `localStorage` 本地存储，每次答题即时保存。
   - 关闭浏览器或下次重新打开，学习数据与历史记录完好无损。

7. **可视化统计大盘**
   - 汇总已学字数、答对/答错总次数、整体正确率。
   - 卡片式展示每个字的详细掌握状态（绿/黄/红高亮指示），支持按“已掌握”、“需复习”分类筛选。

## 🚀 快速使用说明

1. **直接打开**：双击 `index.html` 文件，即可在任意主流浏览器（Chrome、Edge、Safari、Firefox等）中运行。
2. **选择字库测试**：
   - 在首页点击 **常用汉字**。
   - 选择任意预设（如 *小羊上山第一级* ），点击 **开始测试**。
3. **认字答题**：
   - 汉字占据屏幕 80% 大小显示。
   - 孩子朗读后，家长或孩子点击 **“认识”** (✔) 或 **“不认识”** (✘)。
4. **错题复习**：
   - 选择预设组后，点击 **“复习其中错字”**，只针对该组中还没掌握的错字进行再测试。

## 🛠️ 技术栈

- **前端标准**：HTML5, CSS3, JavaScript (ES6+)
- **界面与设计**：Vanilla CSS（CSS Variables, Flexbox, Grid, Keyframe Animations, vmin 自适应字号）
- **数据持久化**：Browser LocalStorage API
- **字体支持**：Noto Sans SC (Google Fonts), 系统标准楷体 ("KaiTi", "Kaiti SC")
